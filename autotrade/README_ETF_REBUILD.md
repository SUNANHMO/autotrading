# ETF 간소화 재구성 (검증용)

운영 ETF 파일: etf_strategy.py / etf_execution.py / etf_state.py

- 수급 고점/저점 대비 20,000 백만원 변화 시 가상 방향 전환
- 실시간 가상 전략은 주문과 독립적으로 갱신
- 실제 주문은 잔고/미체결을 보고 한 번에 한 동작만 수행
- 매수 최우선 매수호가 / 매도 최우선 매도호가 / 가격 추격 없음
- 15:20~15:30 미체결 취소 후 시장가 청산
- 주도주 우선권 유지

**중요:** h_schedule.py의 ETF_LIVE_ORDERS_ENABLED=False. 실계좌 주문 비활성화.
이 코드는 실제 장중 통합 검증 전의 재구성 초안입니다. 운영 서버에 즉시 교체하지 마세요.
과거 단계별 ETF 파일/테스트는 legacy_etf_archive/에 보관했습니다.

기존 a_config.py에 실계좌 API 키와 토큰이 포함될 수 있으므로 ZIP을 외부에 공개하지 마세요.
